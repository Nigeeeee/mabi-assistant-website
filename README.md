# 米列西安 Mobile 小助手（MMH）
Milletian Mobile Helper

整理行囊，讓冒險更從容。

MMH 是為《瑪奇 Mobile》台服玩家製作的非官方桌面助手，
協助查看角色背包、倉庫物品與追蹤冒險日常。

## 網站與下載

- [前往介紹網站](https://nigeeeee.github.io/mabi-assistant-website/)
- [下載最新版本](https://github.com/Nigeeeee/mabi-assistant-website/releases/latest)
- [查看版本紀錄](https://github.com/Nigeeeee/mabi-assistant-website/releases)

## 主要功能

- 帳號與角色資料整理
- 背包、角色倉庫與共同倉庫物品查詢
- 每日與每週進度追蹤

物品與進度以最近一次成功同步的紀錄為準，
實際支援內容請參考各版本說明。

## 開始使用

1. 前往下載頁，閱讀版本說明並下載完整可攜式壓縮包。
2. 解壓縮至可寫入的本機資料夾，不要直接在壓縮包內執行。
3. 依隨附說明啟動助手；使用網路擷取功能前需另行安裝 Npcap。
4. 進入遊戲並完成資料同步；倉庫資料需開啟對應倉庫取得。

更新或搬移前，請先關閉程式並備份使用者資料。
