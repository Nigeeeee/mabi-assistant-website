首次使用：安裝 Npcap

Npcap 是助手偵測遊戲同步資料所需的元件。已安裝的電腦可略過此步驟。

前往 Npcap 官方下載 ↗
  1. 在官方下載區點選「Npcap … installer」下載 Windows 安裝程式。
  2. 執行下載的安裝程式，依畫面指示完成安裝。
  3. 重新開啟助手，在「設定 → 偵測設定」確認網卡，再登入遊戲或切換地圖同步。
查看 Npcap 安裝與同步指引 →
