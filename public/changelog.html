2026-10-04 · 正式發布

MMH v0.9.0

本次已發布內容的正式版號更正為 v0.9.0。先前誤沿用 v0.8.0，現已統一程式內部版本、下載包與自動更新資訊。相較最近公開的 v0.8.0，本次主要是版號與發布紀錄更正。

  • Windows x64 自包含版本，包含 .NET 執行元件。
  • 提供可攜式資料保存、安全寫入與備份機制。
  • 目錄整理版將程式放入 app，個人資料、設定與日誌集中於 userdata，根目錄提供啟動器。

完整下載包、更新包與 SHA-256 校驗檔已提供於 GitHub Releases。

  • 日夜森林介面與帳號、角色整理。

v0.9.0 功能與限制

日常追蹤與介面

包含每日作業總覽、四種視窗大小預設、晨光／月夜美術與工具提示。週末團隊副本、週末深淵任務獨立追蹤，週一重置。

已知限制與待驗證項目

  • 召喚結界與黑色坑洞尚未完整支援完成當下的即時次數更新，可能需切換地圖取得完整同步。
  • 遊戲版本或封包格式變更可能影響同步；資料不足時顯示未同步。
  • 會員代碼尚未完全對照，資源上限需確認帳號設定。
  • Windows 11、乾淨電腦與真實多螢幕 DPI 情境仍待驗證。
  • 每次啟動檢查更新，上限 5 秒；失敗時可重試或先使用目前版本。更新需使用者確認，並核對正式簽章與檔案雜湊。
  • 目前只提供 Windows x64 版本；沒有其他架構的公開下載。
