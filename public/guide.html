FIELD GUIDE / 使用指南

第一次出發，
從這裡開始。

先取得同步紀錄，再把行囊與日常交給手札整理。

安裝Npcap 下載首次同步角色切換背包與倉庫日常進度以物易物釘選縮小至通知區完整包手動更新介面與治癒欄位增益與紫洞文字與浮窗設定常見問題

01 / 準備

安裝與啟動

v0.31.2 已發布，首次安裝與舊版升級請下載完整包。

首次安裝與本次舊版升級均使用 v0.31.2 完整包。

完整包已包含 .NET 10 執行環境，不需要另外安裝 .NET；網路擷取仍需要 Npcap。

  1. 將完整 ZIP 解壓到可寫入的新資料夾，勿直接在壓縮檔內執行，也不要只移動 EXE。
  2. 如需網路擷取，請安裝 Npcap；已安裝的電腦可沿用。
  3. 開啟資料夾根目錄的「啟動助手.exe」。
  4. 在「設定 → 偵測設定」確認網卡與擷取狀態。

升級前請先依下方「v0.31.2 完整包手動更新」保留原 userdata。

已完成本批 Win11 啟動、資料保留與更新恢復的限定範圍驗證；不代表所有 DPI、視窗操作及遊戲情境均已驗證。本版未加 Authenticode 程式碼簽章，不保證消除 SmartScreen／防毒警告，亦未確認可解決遊戲 ERROR 88。

首次安裝 / Npcap

Npcap 在哪裡下載？

請直接前往 Npcap 官方網站，下載 Windows 安裝程式。助手需要 Npcap 才能偵測新的遊戲同步資料；如果只是查閱已保存資料，可以先略過。

前往 Npcap 官方下載 ↗

  1. 在官方網站的下載區，選擇「Npcap … installer」。一般使用者需要的是安裝程式，不是 SDK、debug symbols 或 source code。
  2. 執行下載的安裝程式，依畫面指示完成安裝；若 Windows 要求安裝權限，確認是剛下載的 Npcap 安裝程式。
  3. 完成後重新開啟 MMH，在「設定 → 偵測設定」選擇目前連線的網卡。
  4. 登入遊戲或切換地圖，等待角色與進度同步；背包／保管箱可開啟遊戲內對應頁面取得資料。

已安裝 Npcap 的電腦不必每次更新助手都重新安裝。若安裝程式要求重新啟動 Windows，請先依指示重新啟動，再開啟助手。

02 / 取得紀錄

首次同步

啟動助手後登入遊戲角色或切換地圖，等待完整同步。背包、活動與倉庫的更新時機不同，必要時請開啟對應遊戲頁面。

角色倉庫、公用保管箱需要分別在遊戲內開啟，才能取得對應紀錄。「未同步」代表資料不足，不代表物品為零或任務已完成。

03 / 整理角色

角色切換與順位

從左側角色清單選擇角色，查看該角色最近同步的紀錄。點帳號旁的筆形按鈕可修改帳號名稱與角色順位；每日作業會依相同順序呈現。

切換查閱角色不會代替你切換遊戲角色，也不會自動操作遊戲。

v0.24.0：帳號設定及左側清單右鍵選單可刪除帳號／角色，操作前須確認。刪除只清除小助手本機紀錄，不會刪除遊戲帳號或角色；之後取得完整遊戲同步資料時可能重新建立。

04 / 整理行囊

背包與倉庫操作

  1. 選擇「保管箱／背包」索引頁。
  2. 輸入名稱或選擇分類，篩選已同步物品。
  3. 左側切換角色保管箱／公用保管箱，右側查看目前角色背包。
  4. 停留物品可查看持有數量提示；不同角色的紀錄可能不是同時同步。

v0.22.0：保管箱、公用保管箱與角色背包顯示總重量及物品重量；由放大鏡設定調整稀有度篩選與排序。設定浮窗可點擊外部或切換分頁關閉。未取得可靠同步資料時不推算總重量；重量與數量以最近遊戲同步資料為準。

v0.24.0：背包總重量增加最大重量上限；無可靠資料時保留待同步提示，不以猜測值代替。

05 / 查看日常

每日與每週進度

「每日作業」依角色並列顯示進度；詳細任務與活動可從對應索引頁查看。已完成、剩餘次數與未同步各自呈現，請以遊戲當下畫面為準。

銀幣與魔族供品的提醒會考量未來 24 小時是否達到上限。會員上限不同，請在資源上限設定確認帳號使用的數值。

以物易物的每日作業完成狀態依釘選項目判定。尚未對照或未同步的條目無法可靠判斷完成。

v0.24.0：深淵有上週未領戰利品時顯示「尚未領取上周戰利品」；本週沒有挑戰紀錄時顯示「本周尚未挑戰」，已有紀錄則顯示 1/3、2/3、3/3。未同步仍保留提示。

戰鬥分析

v0.25.0：改善技能與持續傷害分類、分組及 DPS 計算。單選怪物時，交戰時間採目前角色對該怪物首次至最後一次傷害的間隔，包含停手時間；主視窗、技能列表與簡易浮窗使用一致的計時方式。全場時間另作參考，切回全部目標可恢復全場統計，原始紀錄不因切換目標改變。只有單次命中或所有命中發生於同一時間時，顯示時間不足，不計算 DPS。

在「其他工具」開啟戰鬥分析或簡易顯示。助手啟動偵測後即接收戰鬥資料，不必先開啟分析視窗；切換角色或剛啟動時，請先完成角色同步。統計保留至下一場戰鬥，可查看角色、目標、技能與增益；治療統計尚未提供。染色助手仍在開發，本版不顯示入口。

以物易物釘選設定

點「清除篩選」右側的設定齒輪，可選擇所有角色共用釘選，或勾選一起同步的角色與清單來源。

按「儲存」才套用；關閉視窗、點外部、按 Esc 或切換分頁，會放棄未儲存的變更。切回共用時需指定來源角色，按儲存後才清除個別釘選與同步成員設定。

儲存失敗時會保留編輯內容、還原原設定並提示重試；儲存採用來源角色最新的釘選清單。

縮小至系統通知區

v0.25.0：最小化按鈕左側新增縮小至系統通知區按鈕，可由通知區圖示還原小助手。設定可選擇縮小主視窗時是否一併隱藏浮窗。

文字大小與加工詳細浮窗

v0.26.0：設定新增文字大小，可將主介面與主設定視窗文字調整為 100%～150%；先預覽，再按「套用」保存。戰鬥與加工浮窗維持原字體。

加工詳細浮窗設定可分別開關六類浮窗，設定視窗開啟時靠近小助手主視窗。狀態與「完工倒數」顯示於同一行，全部完成時隱藏倒數；本版也修正點擊穿透操作。

診斷錄製中可以開啟設定；設定視窗開啟時，仍可停止錄製。

v0.27.0 持有貨幣與更新方式

活動／資源的「持有貨幣」可展開查看全部、伺服器與角色貨幣，支援捲動與拖移。活動貨幣不列入此區，銀幣與魔族貢品維持上方資源欄顯示。

啟動相關改善需使用完整包；舊版內建更新只替換 app，不會更換根目錄啟動器與更新工具。請先關閉助手並備份 userdata，再使用新版完整包，保留原 userdata。

Windows 11 尚無實機驗證，啟動提示與記錄改善不代表所有啟動問題均已排除。

v0.31.2 完整包手動更新

從 v0.31.1 或更舊版本升級，本次請重新下載完整包，勿只覆蓋 app。

  1. 下載 MMH-0.31.2-portable-win-x64.zip，完整解壓縮到新的資料夾。
  2. 正常關閉原本的小助手與浮窗，備份舊資料夾內的完整 userdata。
  3. 將舊 userdata 複製到新版根目錄，保留資料夾內所有內容；不要以新版的空資料夾覆蓋舊資料。
  4. 執行新版根目錄的「啟動助手.exe」，確認角色、物品與設定保留後再整理舊程式。

userdata 與舊版資料通用；請複製原本整個資料夾，不要混合不同帳號的資料檔。

若要保留診斷匯出檔，也請搬移與 userdata 並列的 diagnostics 資料夾。

v0.31.1 過渡版提示

本版僅提供完整新版的下載與資料搬移說明，不再進入舊主介面。

更新至本過渡版後，按「下載完整新版」開啟官方下載頁。按「結束」或關閉視窗會結束程式；完成新版搬移後即可繼續使用小助手。

v0.31.0 介面與戰鬥欄位

活動／資源與每週挑戰調整空間配置，保管箱／背包調整釘選標記位置；製作圖卡會隨窄介面縮放，補齊其他分類的圖示與稀有度背景。

重新開啟小助手時還原原本開啟的浮窗，浮窗設定盡量顯示在設定按鈕附近。冒險家通行證燃燒週說明補充最後兩週與點數倍率。

戰鬥分析加入治癒頁籤與 HPS 欄位，但自身／隊友來源判定與排除藥水尚未完成實戰驗證，不能視為完整回血統計；來源不足時顯示未就緒或部分資料。

本次接收修正已通過隔離測試，尚未證明是先前實戰漏收的唯一原因。Windows 11 實機相容性、原 A104 啟動錯誤及防毒誤判仍待確認。

v0.30.0 增益效果與紫洞提醒

增益效果浮窗可查看名稱、剩餘時間與效果說明，並可設定固定顯示效果。未偵測到效果時保持空白；過圖或重新登入時顯示「未同步」，同名但效果不同的增益會分別保留。

浮窗首次開啟時出現在小助手附近；手動拖移後記住位置，關閉再開啟仍沿用。地圖雷達可從標題與頂部空白區域拖移。

頁首可查看「通往深淵的黑色坑洞」狀態與通知設定；下次開啟依本機關閉時間加 36 小時預估。紫洞時間優先使用本機遊戲資料，沒有可用本機時間時，另顯示 MMD 非官方參考；參考資料不觸發本機實收通知。通知設定的完整說明可透過工具提示查看。

製作／加工下拉篩選標籤統一為橢圓形，點選右側箭頭開啟選單。佈告欄卷軸詳情、銀幣與魔族供品的完成條件可透過工具提示查看。

v0.29.0 釘選與製作操作

保管箱／背包可切換釘選來源；小助手自行釘選可選擇帳號共用或各角色分開記錄。製作／加工提供快速製作與配方星號釘選，並加入裝飾配方及主分類下拉篩選。

活動／資源可查看冒險家通行證等級、進度、期間與點數獲得方法；燃燒周與點數詳情可透過工具提示查看。

點選底部時間可設定顯示時區；每日與每週重置仍依台灣時間計算。

v0.28.0 材料與持有提示

以物易物的材料不足提醒只計算目前角色身上的材料，詳細持有、需要及缺少數量可在標籤上查看。滑鼠停在材料與兌換物上，可查看各角色及保管箱的持有狀況。

角色保管箱與公用保管箱顯示目前重量／上限；尚未取得上限時保留待同步提示。

FAQ / 冒險前的小問題

常見問題

資料放在哪裡？如何換電腦？

目前目錄整理版使用 app 存放程式，userdata 保存帳號、角色、設定與備份。先正常關閉，再備份並搬移整個資料夾。早期版本請依包內遷移說明，不直接混合資料。

沒有網路或沒有 Npcap 可以開啟嗎？

可以查閱已保存資料；未安裝 Npcap 時無法擷取新的同步紀錄。每台電腦需自行安裝 Npcap。

為什麼數量或次數沒有更新？

先確認偵測設定、網卡及角色，再切換地圖或開啟對應遊戲頁面。助手顯示最近同步資料，重置後部分項目仍需再次同步。

會自動整理物品或替我完成任務嗎？

不會。這是查閱與追蹤工具，不會替你搬移物品、交換、戰鬥或領取獎勵。

能保證帳號安全、不被封號嗎？

不能。MMH 是非官方玩家工具，請自行了解並遵守遊戲服務條款。

遇到問題怎麼回報？

請前往問題回報入口，提供版本、操作步驟與去識別化截圖。不要上傳私人資料、封包或金鑰。
